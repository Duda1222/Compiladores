O que é um token? E um lexema?

O scanner (analisador léxico) é a primeira fase de um compilador: ele lê o programa como uma fila de caracteres e o separa em pedaços com significado.

  • Lexema: o trecho exato do texto, como while, x ou 3.14.
  • Token: o lexema já classificado, com tipo e posição. Exemplo: 3.14 → LITERAL_DECIMAL, linha 2, coluna 5.

Em Python a indentação também importa. Por isso o scanner gera os tokens NEWLINE (↵), INDENT (→) e DEDENT (←).

  1. Escolha um exemplo (ou escreva o seu) e clique em Analisar código.
  2. Veja o código colorido por categoria e a tabela de tokens.
  3. Use Próximo para acompanhar o scanner token por token.
  4. Teste o exemplo Com erros léxicos para ver como os erros são apontados.
